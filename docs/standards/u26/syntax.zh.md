# Uranium 编程语言词法和语法规范文档 (U26)

ZirconiumTian, 2026 年 11 月 25 日, 星期三

## 词法

"词法" 描述了 U 语言的词法元素, 限定了 U 语言切词器 (Lexer) 产出的词元 (Token) 类型, 同时方便 U 语言切词器对自己的 Token 产出做对照。

Token 流是划分源代码单层级结构的数据表示类型。

### I. 标识符

**标识符, Identifier**, 简写为 `Id`, 是 U 语言中用于指代变量、函数、结构体实例的词法元素。标识符应当由半角大小写英文字母、半角阿拉伯数字和下划线组成, 也就是 `A~Za~z0~9_`。对于下列标识符:

- `variable_name`
- `Tokenizer`
- `decode_to_utf32`

都是合法的例子。标识符的首位字符不能是数字。

- `1st_version`
- `3seconds_ago`

都是非法例子。

U 语言的标识符是大小写敏感的。`Function` 和 `function` 是不同的两个标识符。

U 语言的标识符并不阻止您使用其它全角或半角 Unicode 字符。不过鉴于应用不同语言地区设置的不同操作系统平台, 对于文件编码的默认处理方式可能有偏差, 因此在标识符中使用 ASCII 字符之外的 Unicode 字符是 **不推荐** 的。

> **应报告的词法建议**:<br>
> ```
> Tip: Using ASCII characters for identifiers is recommended.
> ```

### II. 关键字

**关键字, Keyword**, 简写为 `Kwd`, 是 U 语言中字符范围和标识符相同的一组特殊的词法元素。关键字在对应上下文中承担对应功能, 下表是 U 语言在 U26 标准下的关键字:

| 关键字 | 含义 |
| :--- | :--- |
| `and` | 逻辑与运算符。 |
| `break` | 中止当前循环并离开循环体。 |
| `case` | 引出 `switch` 语句的分支。 |
| `catch` | 引出监听错误报告并执行补救措施的语句。 |
| `continue` | 结束本次迭代, 继续下一次迭代。 |
| `else` | 引出 `if` 语句的备选分支。 |
| `false` | 表示假值的布尔字面量。 |
| `fn` | 引出通用函数的声明或定义、函数类型或便携式函数表达式。 |
| `for` | 引出 `for` 循环。 |
| `if` | 引出条件分支。 |
| `in` | 在 `for` 中引出被遍历的表达式, 在数值区间判断中引出区间边界, 在结构体外声明或定义方法时引出所属结构体, 在 `catch` 语句中引出监听表达式。 |
| `none` | 表示无值, 可标注函数无返回值, 也可在 `catch` 语句中表示丢弃错误值。 |
| `not` | 逻辑非运算符。 |
| `or` | 逻辑或运算符。 |
| `report` | 发出可由 `catch` 处理的错误报告。 |
| `return` | 结束函数或方法的执行, 可带返回值。 |
| `struct` | 引出结构体声明或定义。 |
| `switch` | 引出按值匹配的条件分支。 |
| `true` | 表示真值的布尔字面量。 |
| `using` | 导入模块, 用于全局作用域。 |
| `while` | 引出 `while` 循环。 |

> **Lexer 流程建议**:<br>
> 对于符合字符范围, 但是不在上述关键字表或下文类型名表的 Token, 应归类于标识符。

### III. 类型名

**类型名, Typename**, 简写为 `Type`, 是 U 语言中字符范围和标识符相同的用于描述数据类型的一组词法元素。下表是 U 语言在 U26 标准下的类型名:

| 类型名 | 含义 |
| :--- | :--- |
| `bool` | 布尔值, 取值为 `true` 或 `false`。 |
| `int8` | 8 位有符号整数。 |
| `int16` | 16 位有符号整数。 |
| `int32` | 32 位有符号整数。 |
| `int64` | 64 位有符号整数。 |
| `uint8` | 8 位无符号整数。 |
| `uint16` | 16 位无符号整数。 |
| `uint32` | 32 位无符号整数。 |
| `uint64` | 64 位无符号整数。 |
| `float32` | 32 位浮点数。 |
| `float64` | 64 位浮点数。 |
| `char` | `uint8` 的扩展类型, 存储位宽为 8 的字符, `string` 的元素类型。 |
| `rune` | `uint32` 的扩展类型, 存储 UTF-32 字符, `string32` 的元素类型。 |
| `string` | 以 UTF-8 编码的字符串。 |
| `string32` | 以 UTF-32 编码的字符串。 |

### IV. 运算符

**运算符, Operator**, 简写为 `Op`, 是 U 语言中为运算表达式规定运算类型的词法元素。在 U 语言中, 运算符通过操作数的数量不同, 分为不同类型的运算符。

#### 1. 一元运算符

**一元运算符, Unary Operator**, 简写为 `Op.Unary`, 通用格式: `Op Expr`。

U26 标准规定了下列一元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `@` | 取得操作数的只读视图。 |
| `&` | 取得操作数的可写引用。 |
| `->` | 取得指向操作数所表示对象的指针。 |
| `++` | 将整型操作数的值加 1。 |
| `--` | 将整型操作数的值减 1。 |
| `~` | 将整数或浮点数操作数的位模式逐位取反, 产生一个新值。 |
| `-` | 对整数或浮点数操作数取相反数。 |
| `not` | 对 `bool` 操作数取逻辑反值。 |

#### 2. 二元运算符

**二元运算符, Binary Operator**, 简写为 `Op.Binary`。通用格式: `Expr Op Expr`。

U26 标准规定了下列二元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `+` | 求两个数的和。 |
| `-` | 用左操作数减去右操作数。 |
| `*` | 求两个数的乘积。 |
| `/` | 用左操作数除以右操作数。 |
| `=` | 将右操作数的值赋给左操作数所表示的位置。 |
| `+=` | 将左操作数与右操作数相加, 结果存回左操作数。 |
| `-=` | 用左操作数减去右操作数, 结果存回左操作数。 |
| `*=` | 将左操作数与右操作数相乘, 结果存回左操作数。 |
| `/=` | 用左操作数除以右操作数, 结果存回左操作数。 |
| `==` | 判断两个操作数是否相等。 |
| `!=` | 判断两个操作数是否不相等。 |
| `>` | 判断左操作数是否大于右操作数。 |
| `<` | 判断左操作数是否小于右操作数。 |
| `>=` | 判断左操作数是否大于或等于右操作数。 |
| `<=` | 判断左操作数是否小于或等于右操作数。 |
| `[]` | 以括号内的整数为下标访问数组元素。 |
| `.` | 访问结构体的成员或方法, 或访问数据提供的内建方法。 |
| `and` | 当两个布尔操作数都为 `true` 时, 结果为 `true`。 |
| `or` | 当至少一个布尔操作数为 `true` 时, 结果为 `true`。 |

上述六个比较运算符的结果类型都是 `bool`。

#### 3. 三元运算符

**三元运算符, Ternary Operator**, 简写为 `Op.Ternary`, 通用格式: `Expr Op Expr Op Expr`。

U26 标准规定了下列三元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `in` | 按 `a in b, c` 的形式判断 `a` 是否在以 `b` 为下界、`c` 为上界的数值区间内。任一边界可写为 `none`, 表示该侧无界。等效于 `a >= b and a <= c`。 |
| `? :` | 按 `a ? b : c` 的形式写条件表达式。`a` 为 `true` 时选择分支 `b`, 为 `false` 时选择分支 `c`。 |

### V. 分隔符

**分隔符, Delimiter**, 简写为 `Deli`, 是 U 语言中用于表示语句或表达式之间的界限的词法元素。一般情况下, 下列分隔符起到不同的分隔作用:

| 分隔符 | 分隔对象或作用 |
| :--- | :--- |
| `(` `)` | 提升运算表达式优先级、限定调用表达式或函数定义式的接收参数。 |
| `[` `]` | 对一个具有多个元素的数据进行下标访问运算。 |
| `{` `}` | 划定块语句的作用域边界。 |
| `,` | 区分不同参数、区分不同块语句中的元素。 |
| `:` | 区分数据声明标识符和类型、引出便携式函数或普通函数的返回类型。 |
| `;` | 区分不同语句。 |

### VI. 字面量

**字面量, Literal**, 简写为 `Lit`, 是 U 语言中表达编译期确定的具体数据的词法元素。U 语言有下列字面量类型:

#### 1. 整数字面量

**整数字面量, Integer Literal**, 简写为 `Lit.Int`, 描述一个整数数据, 可被以 `uint` 或 `int` 为前缀的类型 (见 [类型名](#iii-类型名) 章节) 接收。

在 U 语言中, 可以通过 2 进制、8 进制、10 进制或 16 进制书写整数字面量。不同进制写法具有不同词法特征, 如下表:

| 进制 | 示例写法 | 词法特征 |
| :--- | :--- | :--- |
| 2 | `0b01100111` | 以 `0b` 为前导, 后接二进制数字 (0 和 1)。 |
| 8 | `033` | 以 `0` 为前导, 后接 8 进制数字 (0 到 7)。 |
| 10 | `1024` | 以非 0 阿拉伯数字为前导, 后接任意阿拉伯数字。 |
| 16 | `0x7c00` | 以 `0x` 为前导, 后接 16 进制数字 (0 到 9 数字及 a 到 f 半角英文字母)。 |

上述包含字母的如二进制和十六进制字面量不限制大小写。如 `0B0010` 和 `0X84b2` 均合法。

#### 2. 浮点数字面量

**浮点数字面量, Floating-Point Literal**, 简写为 `Lit.Float`, 描述一个浮点数数据, 可被 `float32`, `float64` 接收。

浮点数字面量总是按照十进制表示, 中间有一个半角句点作小数点。`3.141592` 和 `0.125` 是合法的浮点数字面量。

半角句点不能出现在首或尾。`.231` 和 `7632.` 是非法浮点数字面量。

> **Lexer 流程建议**:<br>
> 对于浮点数字面量的半角句点, `.231` 和 `7632.` 的报错并不一致。前者报错类型为语法错误, 因为切词器应首先阅读 . 并作为 Period, 后续为整数字面量。而后者是一个未完成的浮点数字面量。
>
> 读取到数字为前导时, 应同时检测半角句点、阿拉伯数字和 16 进制字母, 以及符合前导规范的数字和字母, 以此判断不同的字面量类型。

#### 3. 字符字面量

**字符字面量, Character Literal**, 简写为 `Lit.Char`, 描述一个字符数据, 可被 `char`, `rune` 接收, 或被这两个类型的底层类型 `uint8`, `uint32` 接收。

字符字面量由单引号包裹。比如:

`'C'` `'a'` `','`

都是字符字面量。

##### 3.1. UTF-32 属性签名

对于 `uint8` 数值, 0 至 255 的字符字面量, 可以使用 `char` 类型限定。对于 256 及以上, 2\^32 以下的数据, 为 `uint32` 数据, 应该使用 UTF-32 字符属性。通过在单引号前使用小写字母 `u` 来签名, 如汉字 "中" 使用 UTF-32 字符表示就是:

`u'中'`

这样的数据可以由 `rune` 类型限定, 但是不能被 `char` 限定。

#### 4. 字符串字面量

**字符串字面量, String Literal**, 简写为 `Lit.Str`, 描述一个字符串数据, 可被 `string`, `string32` 接收。

字符串字面量使用双引号包裹, 比如:

`"This is a string!"` `"Love you so much! (>_<)"`

都是字符串字面量。

##### 4.1. 字符串属性签名

如同上一节字符的 [UTF-32 属性签名](#31-utf-32-属性签名) 一样, 字符串同样具有属性签名。字符串具有多种属性签名, 除了 UTF-32 字符串还包含插值字符串和原始字符串。详见下面几个小节。

##### 4.2. 插值字符串

插值字符串是 U 语言原生提供的类型安全的字符串格式化方法。使用 `f` 签名来启用字符串插值, 并使用花括号来嵌入带有值的表达式。如果想要输出花括号本身, 使用双花括号写法 `{{` `}}`。

```ul
f"2 + 3 = {2 + 3}"
f"f(x) = {{a + b[a - (c + x)]}}^2, type: {type}"
```

上面例子中, 假设 `type` 为 `string` 类型数据 `"Function"`, 那么这些例子被插值后的结果是:

```ul
"2 + 3 = 5"
"f(x) = {a + b[a - (c + x)]}^2, type: Function"
```

> **Lexer 流程建议**:<br>
> 对于插值字符串如 `f"2 + 3 = {2 + 3}"`, 应该拆分为 `Lit.Str("2 + 3 = ")` `Lit.Int(2)` `Op(+)` `Lit.Int(3)` 共 4 个 Token, 并且每个 Token 带上 **"在插值字符串内"** 的标志, 可供后续语法分析器生成插值字符串的表达式树。

##### 4.3. 原始字符串

原始字符串是 U 语言中无视转义字符且可以跨行编写的自由的字符串字面量, 使用小写字母 `r` 签名, 并在字符串内部使用小括号 (紧贴双引号) 划定原始字符串的范围。

```ul
r"(This is a
   raw string in the Uranium
   Programming Language!)"
```

上述例子写成单行字符串就是:

```ul
"This is a`n   raw string in the Uranium`n   Programming Language!"
```

##### 4.4. UTF-32 字符串

对于包含 Unicode 字符的字符串, 您可以直接用 `string` 类型限定。

```ul
"アンノウン・マザーグース"
```

上述是一个包含 Unicode 字符的 UTF-8 字符串。可见字符串以 `char` 类型为元素类型, Unicode 码点被紧凑编码。如果要让每个元素保存一个完整的 Unicode 码点, 而非紧凑编码, 可以考虑使用 `rune` 作为元素类型。使用 `u` 签名:

```ul
u"アンノウン・マザーグース"
```

##### 4.5. 混合属性

上述讲解到的属性签名可以混用, 且签名顺序不影响效果。`u` `r` `f` 混用的例子:

```ul
urf"(Project Information:
项目: {project.name}
作者: {project.author}"
许可证: {project.license})"
```

就以 UTF-32 编码模式存储了一个多行带插值的字符串数据。

> **Lexer 流程建议**:<br>
> 对于一些未知的字符串字面量签名 `a"String demo"`, 应该拆分为 `Id` `Lit.Str("String demo")` 共 2 个 Token。在 Lexer 读取字母的时候, 除非连续读取仅包含 `u` `f` `r` 的字母序列, 并紧挨着遇上双引号 (对于字符字面量是单引号) 作为签名。
> ```
> urf "(Raw UTF-32 Format String)"
> ```
> 上述的符合签名规则的字母和双引号间隔一个空白字符, 所以拆分为 `Id(urf)` `Lit.Str("(Raw UTF-32 Format String)")`。

#### 5. 转义序列

字符字面量和普通字符串字面量使用半角反引号 (U+0060) 引出转义序列。原始字符串的正文保留这些字符的原样。

| 转义序列 | 含义 |
| :--- | :--- |
| ``` `` ``` | 半角反引号。 |
| `` `' `` | 半角单引号。 |
| `` `" `` | 半角双引号。 |
| `` `n `` | 换行符 (U+000A)。 |
| `` `r `` | 回车符 (U+000D)。 |
| `` `t `` | 水平制表符 (U+0009)。 |
| `` `0 `` | 空字符 (U+0000)。 |
| `` `033 `` | 转义字符 ESC (U+001B)。 |
| `` `e `` | 转义字符 ESC (U+001B)。 |

在处理转义的字面量中, 与起始引号相同的引号必须转义, 反斜杠可以直接写入。遇到表中未定义的转义序列时, 编译器应报告错误。

### VII. 注释

**注释, Comment**, 简写为 `Com`, 是 U 语言程序中为特定代码添加注解的词法元素。一般情况下, 注释被编译器直接忽略计入空白字符, 除非特殊场景 (IDE 插件解析从注释读取临时配置) 将注释记为 Token。注释不影响程序的运行行为。

U 语言支持两种注释写法:

```ul
// 这是行注释
/* 这是块注释 */
/*
 * 块注释可以跨行使用,
 * 而且可以 /* 嵌套 */
 */
```
写法和现代 C++ 差异不大。值得一提的是 U 语言的块注释支持嵌套。

## 语法

"语法" 描述了 U 语言的语法元素, 限定了 U 语言语法分析器 (Parser) 产出的语法树节点 (Syntax Tree Node) 类型, 同时方便 U 语言语法分析器对自己的语法树产出做对照。

语法树是划分源代码多层级结构的数据表示类型。

### I. 表达式

**表达式, Expression**, 简写为 `Expr`, 是 U 语言中表示值或运算的语法结构。表达式可以包含其他子表达式, 比如调用表达式中的实参和运算表达式中的操作数。

#### 1. 字面量表达式

**字面量表达式, Literal Expression**, 简写为 `Expr.Lit`, 由一个 [字面量](#vi-字面量) 构成, 直接表示源代码中写出的值。字面量表达式所指的数据在编译期就可以确定。

```ul
3.141592
1024
"test"
```

都是字面量表达式。

#### 2. 标识符表达式

**标识符表达式, Identifier Expression**, 简写为 `Expr.Id`, 由一个标识符构成, 用来指代该名称所对应的实体。标识符表达式可以指代变量、常量、结构体和函数等。

```ul
function
VkInstance
```

都是标识符表达式。

#### 3. 原子表达式

**原子表达式, Atom Expression**, 简写为 `Expr.Atom`, 是组成更复杂表达式的基本形式。字面量表达式和标识符表达式都是原子表达式。

#### 4. 运算符表达式

**运算符表达式, Operator Expression**, 简写为 `Expr.Op`, 由运算符和操作数组成。操作数可以是其他表达式, 不同运算类型的运算表达式产生不同类型的值。也有可能不产生值。

##### 4.1. 四则运算

四则运算包括加法、减法、乘法和除法, 分别使用 `+`、`-`、`*` 和 `/`。

| 运算表达式 | 含义 |
| :--- | :--- |
| `a + b` | 求 `a` 与 `b` 的和。 |
| `a - b` | 求 `a` 减去 `b` 的差。 |
| `a * b` | 求 `a` 与 `b` 的乘积。 |
| `a / b` | 求 `a` 除以 `b` 的商。 |

##### 4.2. 比较运算

比较运算用于判断两个操作数之间的相等或大小关系, 结果为 `bool` 值。

| 运算表达式 | 含义 |
| :--- | :--- |
| `a > b` | 判断 `a` 是否大于 `b`。 |
| `a < b` | 判断 `a` 是否小于 `b`。 |
| `a >= b` | 判断 `a` 是否大于或等于 `b`。 |
| `a <= b` | 判断 `a` 是否小于或等于 `b`。 |
| `a == b` | 判断 `a` 是否等于 `b`。 |
| `a != b` | 判断 `a` 是否不等于 `b`。 |

##### 4.3. 逻辑运算

逻辑运算使用逻辑运算符 `not` `and` `or`, 每个运算符的操作数是产生 `bool` 数值的表达式。其中, `not` 是一元运算符, 仅仅接收其右边的一个表达式。`and` 和 `or` 是二元运算符, 接收左右两边两个表达式。

| 运算表达式 | 含义 |
| :--- | :--- |
| `not a` | 对布尔表达式 `a` 取反。 |
| `a > b and a > c` | 两个比较结果都为真时, 结果为真。 |
| `a > b or a > c` | 至少一个比较结果为真时, 结果为真。 |
| `not a > b and a > c` | 对 `a > b` 的结果取反, 再与 `a > c` 的结果作逻辑与。 |
| `not (a > b and a > c)` | 对括号内整个逻辑与表达式的结果取反。 |

`not` 会将右边的第一个表达式作为其操作数并构成一个新的 `not` 逻辑运算表达式。所以 `not a > b and a > c` 实际上是 `(not (a > b)) and (a > c)` 的含义。

##### 4.4. 下标运算

下标运算使用 `a[b]` 的形式访问数组元素, 其中 `a` 是被索引的表达式, `b` 是下标表达式。`b` 必须是产生类型以 `int` 或 `uint` 为前缀的值的表达式。

##### 4.5. 赋值运算

赋值运算符写在两个操作数之间。普通赋值使用 `=`, 复合赋值使用 `+=`、`-=`、`*=` 或 `/=`。自增和自减运算符写在操作数之前。

| 运算类型 | 示例 |
| :--- | :--- |
| 普通赋值 | `a = b` |
| 复合赋值 | `a += b`、`a -= b`、`a *= b`、`a /= b` |
| 自增、自减 | `++a`、`--a` |

#### 5. 调用表达式

**调用表达式, Call Expression**, 简写为 `Expr.Call`, 由被调用部分和紧随其后的实参列表组成。实参列表用圆括号包围, 可以为空。

| 调用表达式 | 含义 |
| :--- | :--- |
| `test("value")` | 以字符串字面量 `"value"` 为实参调用 `test`。 |
| `next()` | 调用 `next`, 实参列表为空。 |

#### 6. 便携式函数表达式

**便携式函数表达式, Portable Function Expression**, 简写为 `Expr.PtFunc`, 由 `fn`、形参列表和作为函数体的块语句组成。形参列表之后可以写返回类型标注。

```ul
fn(arg: int32): int32 {
	return arg + 1;
}
```

是一个便携式函数表达式, 产生一个数据类型为函数类型的数据, 此函数的类型为 `fn(int32):int32`。

### II. 语句

**语句, Statement**, 简写为 `Stmt`, 是组成程序的语言元素。

#### 1. 块语句

**块语句, Block Statement**, 简写为 `Stmt.Block`, 是一个可包含其他子语句的语句。使用花括号 `{` `}` 表示一个块语句, 并在块语句内可以写入包括块语句在内的其它语句。

#### 2. 表达式语句

**表达式语句, Expression Statement**, 简写为 `Stmt.Expr`, 由一个表达式和结尾的分号构成, 比如一次单独的函数调用。

| 示例 | 语句类型 | 表达式结构 |
| :--- | :--- | :--- |
| `test("value");` | 调用语句 | 调用表达式, 以字符串字面量为实参。 |
| `++index;` | 赋值语句 | 自增表达式, 以标识符为操作数。 |
| `name = ask_name();` | 赋值语句 | 赋值表达式, 右操作数是调用表达式。 |

#### 3. 声明语句

**声明语句, Declaration Statement**, 简写为 `Stmt.Decl`, 用于在程序中引入名称, 并给出该名称对应的类型或签名。声明和赋值可以同时进行, 此时赋值操作成为初始化运算, 一个包含初始化运算的声明语句为定义语句。详见 [定义语句](#4-定义语句)。

##### 3.1. 数据声明

**数据声明, Data Declaration**, 简写为 `Stmt.Decl.Data`。一般数据声明语句采用 `Id: Type;` 的形式。

```ul
age: int32;
name: string;
```

就声明了两个类型分别为 `int32` 和 `string` 的变量数据。类型名可以添加两种不同的限定, 分别是形式限定和传递限定。形式限定符号有 `[]` `!`, 传递限定符号有 `&` `@` `->`, 见下表:

| 类型 | 含义 |
| :--- | :--- |
| `Type` | 数据类型为 `Type`。 |
| `Type!` | 数据类型为 `Type`, 只读。 |
| `Type[]` | 元素数据类型为 `Type` 的动态数组。 |
| `Type[n]` | 元素数据类型为 `Type` 的定长数组, 长度为 `n`。 |
| `Type![]` | 元素类型为只读 `Type` 的动态数组。 |
| `Type[]!` | 元素类型为 `Type` 的只读定长数组。长度通过初始化式在编译期确定。 |
| `&Type` | 对 `Type` 类型数据的引用。 |
| `@Type` | 对 `Type` 类型数据的只读视图。 |
| `->Type` | 对 `Type` 类型实例的一个指针。 |
| `->Type!` | 对只读的 `Type` 类实例的一个指针。 |
| `->Type[]` | 指向一个元素类型为 `Type` 的动态数组的一个指针。 |
| `&Type!` | 对一个只读的 `Type` 类数据的引用, 效果和 `@` 差不多， 实际有所差异。 |
| `Type[][]` | 元素为 `Type` 的二维数组。 |

如果想要表达一些有歧义的类型, 比如只读的指针, 多维数组, 可以为类型名和不同限定符之间使用括号划定优先级。比如:

| 类型 | 含义 |
| :--- | :--- |
| `(->Type)!` | 一个指向 `Type` 类实例的只读指针。 |
| `(->Type)[]` | 指向一个元素类型为指向 `Type` 的指针的的动态数组。 |
| `@->Type` | 一个对 `Type` 类指针的只读视图。 |
| `->&Type` | 指向一个 `Type` 类引用的指针。 |
| `(fn(int32): int32)` | 函数类型, 函数为接收一个 `int32` 参数的返回 `int32` 数据的函数。 |

上表提到的函数类型, 详见下方 [便携式函数声明](#33-便携式函数声明)。

> **应报告的语法建议**:<br>
对于写法 `->int32[]` 可以给出下列语法警告和建议: 
> ```
> Warning: `->int32[]` is parsed as a pointer to a dynamic array of `int32`.
> Tip: Write `->(int32[])` to make the grouping explicit, or `(->int32)[]` if you meant a dynamic array of pointers.
> ```

##### 3.2. 函数声明

**函数声明, Function Declaration**, 简写为 `Stmt.Decl.Func`。通用函数声明采用 `fn Id(Args...): Type;` 的形式, 形参可以只写类型。无返回值时可以省略 `: Type`。

```ul
fn ask_for_age(): int32;
fn print_about(): none;
```

上述两个语句声明了一个返回类型为 `int32` 的函数 `ask_for_age` 和一个无返回值函数 `print_about`。无返回值函数的返回类型为 `none`, 可以省略, 即写为:

```ul
fn print_about();
```

声明效果和前一个例子相同。

多个形参用逗号分隔, 无形参时保留空括号。下面的声明只写了两个形参的类型:

```ul
fn sum(int32, int32): int32;
```

##### 3.3. 便携式函数声明

**便携式函数声明, Portable Function Declaration**, 简写为 `Stmt.Decl.PtFunc`。便携式函数值可以存入函数类型的数据, 比如 `portable: (fn(int32): int32);`。函数类型的形参列表只写类型, 无返回值时可以省略返回类型标注。

```ul
portable: (fn(int32): int32);
notify: fn();
```

`portable` 的函数类型接收一个 `int32` 形参并返回 `int32`。`notify` 的函数类型无形参、无返回值, 也可以写成 `fn(): none`。函数类型也可以用作通用函数的形参类型或返回类型。

##### 3.4. 结构体声明

**结构体声明, Structure Declaration**, 简写为 `Stmt.Decl.Struct`。结构体前置声明采用 `struct Id;` 的形式, 成员列表在结构体定义中给出。

```ul
struct Position;
```

##### 3.5. 结构体方法声明

**结构体方法声明, Structure Method Declaration**, 简写为 `Stmt.Decl.Method`。结构体方法在结构体体外声明, 采用 `fn Id(Args...) in Structure: Type;` 的形式。结构体方法是属于结构体的特殊函数, 其他写法和函数写法完全一致。

```ul
fn origin_index() in Position: int32;
```

#### 4. 定义语句

**定义语句, Definition Statement**, 简写为 `Stmt.Def`, 是同时完成声明和初始化操作的语句类型。定义语句可以定义变量、常量、结构体、函数等。

##### 4.1. 数据定义

**数据定义, Data Definition**, 简写为 `Stmt.Def.Data`。一般数据定义语句采用 `Id: Type = Expr;` 的形式, 其中 `Expr` 为初始化式。数据定义语句的声明部分和 [数据声明](#31-数据声明) 章节讲述的一致, 将声明语句末尾的分号改为赋值运算符 `=` 和初始化式。

```ul
age: int32 = 17;
name: string = "Lovely Puski";
```

就是两个定义语句, 定义了具有初始数据的两个变量。

以字符串字面量初始化数据时, 字面量的类型必须与声明的类型一致。普通字符串字面量用于 `string`, 带 `u` 签名的字符串字面量用于 `string32`。

```ul
message: string = "Hello";
message32: string32 = u"你好";
```

##### 4.2. 函数定义

**函数定义, Function Definition**, 简写为 `Stmt.Def.Func`。通用函数定义采用 `fn Id(Args...): Type { ... }` 的形式, 每个形参都写作 `Id: Type`, 同数据声明写法一致。

```ul
fn find_char_in_string(target: char, from: string): bool {
	for element in from {
		if element == target {
			return true;
		}
	}
	return false;
}
```

函数可以用 `none` 表示无返回值, 也可以省略返回类型标注。函数的返回类型也可以是函数类型, 见 [便携式函数定义](#43-便携式函数定义)。

##### 4.3. 便携式函数定义

**便携式函数定义, Portable Function Definition**, 简写为 `Stmt.Def.PtFunc`。便携式函数表达式可以初始化函数类型的数据, 也可以在数据声明后通过 `Id = Expr;` 赋值。

```ul
portable: (fn(int32): int32);
portable = fn(arg: int32): int32 {
	return arg + 1;
};

notify: fn() = fn() {};
```

通用函数可以接收或返回便携式函数。传递已经保存的函数值时, 可以直接写该数据的名称。

```ul
fn apply(value: int32, operation: (fn(int32): int32)): int32 {
	return operation(value);
}

fn select_operation(): (fn(int32): int32) {
	operation: (fn(int32): int32) = fn(arg: int32): int32 {
		return arg + 1;
	};
	return operation;
}

operation: (fn(int32): int32) = select_operation();
result: int32 = apply(32, operation);
```

在上面的例子中, `apply(32, operation(32))` 不合法, 因为 `operation(32)` 的结果类型为 `int32`。便携式函数表达式不能直接写在调用的实参列表中。

##### 4.4. 结构体定义

**结构体定义, Structure Definition**, 简写为 `Stmt.Def.Struct`。结构体定义采用 `struct Id { ... };` 的形式, 花括号内只写数据成员, 其中可以包含函数类型的数据。

数据成员可以在声明时提供初始化式。下面的 `adjust` 是保存便携式函数值的数据成员。

```ul
struct Position {
	row: int32;
	column: int32 = 4;
	adjust: (fn(int32): int32) = fn(arg: int32): int32 {
		return arg + 1;
	};
};
```

结构体实例也可以按位置赋值。花括号内的值按数据成员的声明顺序排列, 用逗号分隔。`none` 表示跳过对应成员。

```ul
position: Position;
position = {42, 42, none};
position = {none, 17, none};
```

##### 4.5. 结构体方法定义

**结构体方法定义, Structure Method Definition**, 简写为 `Stmt.Def.Method`。结构体方法在结构体体外定义, 采用 `fn Id(Args...) in 结构体名: Type { ... }` 的形式。

```ul
fn origin_index() in Position: int32 {
	return 0;
}
```

#### 5. 条件控制语句

**条件控制语句, Branching Statement**, 简写为 `Stmt.Branch`, 根据条件或匹配结果选择要执行的分支。

##### 5.1. if-else 语句

`if` 后写一个 `bool` 类型的条件表达式, 再写一个块或一条语句。可以追加 `else` 分支, 其主体也可以是块或单条语句。用另一条 `if` 语句作为 `else` 的主体, 就构成 `else if`。

```ul
if score >= 90 {
	excellent();
} else if score >= 60 {
	pass();
} else {
	retry();
}
```

两个分支都可以各写一条语句:

```ul
if ready start();
else retry();
```

##### 5.2. switch-case 语句

`switch` 后写要匹配的表达式, 再用花括号包围各个 `case` 分支。每个普通分支包含一个匹配值和一个块, 被匹配的值须支持 `==` 比较, 各普通分支的匹配值不得相同。分支以逗号分隔, 最后一个分支后的逗号可以省略。

`case none` 是默认分支, 最多出现一次。

```ul
switch answer {
	case "yes" { accept(); },
	case "no" { reject(); },
	case none { retry(); },
}
```

##### 5.3. 三元分支表达式语句

三元分支写作 `a ? b : c`。条件表达式 `a` 必须是 `bool` 类型。每个分支可以是表达式, 也可以是 `return`、`break` 或 `continue` 语句。跳转语句作为分支时省略自身的分号, 整条三元分支语句以一个分号结束。

```ul
ready ? start() : wait();
```

包含 `return` `break` 等语句的写法则有这样一份示例:

```ul
fn choose(yes: bool): string {
	while true {
		yes ? return "s" : break;
	}
	return "";
}
```

`break` 后面的分号结束整条三元分支语句。在分支内使用跳转语句时, 仍须满足 [跳转语句](#7-跳转语句) 的使用条件。

两个分支都可以写成原子表达式:

```ul
age >= 18 ? "adult" : "teen"
```

#### 6. 循环语句

**循环语句, Loop Statement**, 简写为 `Stmt.Loop`, 用于反复执行循环体。循环体可以是一个块或一条语句。

##### 6.1. for 语句

`for` 支持遍历形式和三段式。遍历形式写作 `for Id in Expr`, 其中 `Id` 为迭代变量名, `Expr` 必须是定长数组、动态数组或字符串类型的表达式。

```ul
for item in items {
	use(item);
}
```

循环体只有一条语句时, 也可以直接写在遍历表达式之后:

```ul
for item in items use(item);
```

三段式写作 `for Init; Condition; Update`, 然后写循环体。用分号分隔循环头中的三个部分。

```ul
for i: int32 = 0; i < 3; ++i {
	use(i);
}
```

三段式同样可以使用单条语句作为循环体:

```ul
for i: int32 = 0; i < 3; ++i use(i);
```

##### 6.2. while 语句

`while` 后写一个 `bool` 类型的条件表达式, 再写循环体。

```ul
while ready {
	do();
}
```

循环体也可以是一条语句:

```ul
while ready do();
```

#### 7. 跳转语句

**跳转语句, Jump Statement**, 简写为 `Stmt.Jump`, 用于结束循环、进入下一次迭代或返回调用方。

##### 7.1. break 语句

**break 语句, Break Statement**, 简写为 `Stmt.Jump.Brk`。`break;` 写在 `while` 或 `for` 循环体的块语句内, 用于结束当前循环。

```ul
while true {
	data.append(read_from_user());
	if data.count > max_capacity {
		putln("At max capacity!!!");
		break;
	}
}
```

##### 7.2. continue 语句

**continue 语句, Continue Statement**, 简写为 `Stmt.Jump.Cont`。`continue;` 可以写在循环体内, 用于结束本次迭代。

```ul
for item in items {
	if item == stop_value {
		break;
	}
	if item == skip_value {
		continue;
	}
	use(item);
}
```

##### 7.3. return 语句

**return 语句, Return Statement**, 简写为 `Stmt.Jump.Ret`。有返回值的函数或方法使用 `return Expr;`。无返回值的函数或方法可以写 `return;`。

```ul
fn print_when_ready(ready: bool) {
	if not ready {
		return;
	}
	print_about();
}
```

#### 8. 错误处理语句

**错误处理语句, Error Handling Statement**, 简写为 `Stmt.Error`, 包括报告错误的 `report` 语句和处理错误报告的 `catch` 补救语句。

##### 8.1. report 语句

报告语句采用 `report Expr;` 的形式。`Expr` 的值是报告的错误值, 其类型供带类型的 `catch` 补救语句匹配。下面的 `read` 报告一个 `string` 类型的错误值。

```ul
fn read() {
	report "Unable to read input.";
}
```

##### 8.2. catch 补救语句

`catch` 语句由错误值绑定说明、监听表达式 (`ListenExpr`) 和作为补救措施的块语句组成。监听表达式可以是调用表达式 (`Expr.Call`), 也可以是包含调用表达式的运算表达式 (`Expr.Op`)。

```
catch Id: Type in ListenExpr Stmt.Block
catch none in ListenExpr Stmt.Block
```

两种形式都用关键字 `in` 引出监听表达式。第一种形式用 `Id: Type` 指定接收错误值的名称和类型。错误值的类型须与 `Type` 匹配。`Id` 只在补救块内可见。

```ul
catch err: string in read() {
	putln(err);
}
```

第二种形式用 `none` 表示匹配任意类型的错误报告, 并省略错误值绑定。

```ul
catch none in read() {
	retry();
}
```

监听表达式也可以写成包含嵌套调用的赋值表达式:

```ul
catch err: string in age = parse(read_input()) {
	putln(err);
}
```
