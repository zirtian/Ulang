# U 编程语言语法规范文档 (U26 标准)

ZirconiumTian, 2026 年 11 月 21 日

## 词法

### I. 标识符

**标识符, Identifier**, 简写 Id, 是 U 编程语言 (下列简称 U 语言) 在源代码中用于描述变量、函数、成员、方法、结构体等使用的词法元素。适用的字符范围是 `[A~Za~z0~9_]`, 也就是所有半角大小写字母、半角阿拉伯数字和下划线, 并且以 **非阿拉伯数字** 打头。下列:

- `function_name`
- `Tokenizer`
- `decodeUTF32`

都是合法的例子。

特别地, 作为 Identifier, U26 不会阻止您使用一些全角或半角的 Unicode 字符。除了下列 Unicode 空格和标点不被允许:

| 字符 | Unicode 码点 | 字符 | Unicode 码点 |
| :--- | :--- | :--- | :--- |
| `　` | U+3000 | `、` | U+3001 |
| `‘` | U+2018 | `’` | U+2019 |
| `“` | U+201C | `”` | U+201D |
| `：` | U+FF1A | `；` | U+FF1B |
| `，` | U+FF0C | `。` | U+3002 |

那么, 以一些中文 Unicode 字符举例:

| 标识符 | 是否合法 | 标识符 | 是否合法 |
| :--- | :--- | :--- | :--- |
| `甲乙` | 是 | `甲，乙` | 不是 |
| `“”` | 否 | `你好U语言` | 是 |
| `→here` | 是 | `Software：Installer` | 不是 |

> **编译规则**: 使用合法 ASCII 和 Unicode 字符命名的非关键字和非类型名的标识符, 编译器 **不应** 报错或给出警告。<br>
> 标识符含有非法字符时, 报告 `Unexpected character in identifiers.`

U 语言的标识符命名不能和关键字或类型名冲突。

### II. 关键字

**关键字, Keyword**, 简写 Kwd, 在词法层面上是一组特殊的标识符。它们分别是:

| 关键字 | 含义 |
| :--- | :--- |
| `and` | 逻辑与。 |
| `break` | 循环中的跳转语句。 |
| `case` | 在 switch 语句中使用。 |
| `continue` | 循环中的跳转语句。 |
| `else` | else 条件分支语句。 |
| `failed` | 适用于错误处理块, 声明一个补救方案。 |
| `false` | 布尔字面量, 表示假值。 |
| `fn` | 声明一个函数。 |
| `for` | for 循环语句。 |
| `if` | if 条件分支语句。|
| `in` | in 语句, 可以在 for 语句中使用, 或者用于判断一个整数或者浮点数是否在指定的值大小范围内, 也可以用于结构体成员的外部实现。 |
| `or` | 逻辑或。 |
| `none` | 通用关键字, 表示空数据或者无返回值函数的返回类型。 |
| `not` | 逻辑非。 |
| `report` | 报告一个错误, 被 failed 语句监听和捕获。 |
| `return` | 返回语句, 用户函数和方法中。 |
| `struct` | 结构体声明。 |
| `switch` | 声明一个 switch 语句。 |
| `true` | 布尔字面量, 表示真值。 |
| `using` | 模块调用。仅仅可以在全局作用域或者全局作用域下的第一层 if else 中使用。 |
| `while` | while 循环语句。 |

上述关键字不能用作标识符。

> **编译规则**: 使用关键字命名的标识符应该报错并拒绝进一步编译。<br>
> 报告错误为: `Should not be used here as an identifier`。

### III. 类型名

**类型名, TypeName**, 简写 Type, 是 U 语言中描述数据类型的特殊标识符。它们分别是:

| 类型名 | 含义 |
| :--- | :--- |
| `int8`、`int16`、`int32`、`int64` | 有符号整数。 |
| `uint8`、`uint16`、`uint32`、`uint64` | 无符号整数。 |
| `char`、`rune` | 字符。 |
| `string` | UTF-8 字符串。 |
| `string32` | UTF-32 字符串。 |
| `float32`、`float64` | 浮点数。 |
| `bool` | 布尔数据。 |

上述类型名不能被用作标识符的命名。

> **编译规则**: 使用类型名命名的标识符应该报错并拒绝进一步编译。<br>
> 报告错误为: `Should not be used here as an identifier`。

### IV. 运算符

**运算符, Operator**, 简写 Op, 是 U 语言中用于在数据间表达运算或传递关系的符号。运算符分为 **一元运算符, Unary Operator**、**二元运算符, Binary Operator** 和 **三元运算符, Tripleray Operator**。

一些运算符写作关键字。

| 元 | 一般格式 | 常见运算 |
| :--- | :--- | :--- |
| 1 | `Op Id` | 指针、引用、视图、布尔取反、自增自减和下标等。 |
| 2 | `Id Op Id` | 数学四则运算、布尔比较等。 |
| 3 | `Id Op Id Op Id` | `?:` 条件运算、`in` 区间判断。 |

U 语言的一元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `not a` | 对数据或表达式 a 布尔取反。 |
| `&a` | 数据 a 的可写引用。 |
| `@a` | 数据 a 的只读视图。 |
| `->a` | 数据 a 的指针指向关系/地址。 |
| `~a` | 对一个整数或者浮点数及对应表达式 a 的数据按位颠倒。 |
| `++a` | 整数自增。 |
| `--a` | 整数自减。 |
| `-a` | 取相反数, 前提是 a 的数据类型为 float, int 的任意之一。 |

U 语言的二元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `a + b` | 对整数或者浮点数 a、b 求和。 |
| `a - b` | 对整数或者浮点数 a、b 求差。 |
| `a * b` | 对整数或者浮点数 a、b 求乘积。 |
| `a / b` | 整数或浮点数除法。 |
| `a[b]` | 下标运算, 访问切片或数组 a 的第 b 个元素。b 只能为 int 或 uint 类型。 |
| `a.b` | 访问结构体 a 的成员/方法 b，或者访问对特定数据 a 使用内建方法 b。 |
| `a = b` | 赋值。 |
| `a > b` | 判断 a 是否大于 b。 |
| `a < b` | 判断 a 是否小于 b。 |
| `a == b` | 判断 a 是否等于 b。 |
| `a != b` | 判断 a 是否不等于 b。 |
| `a >= b` | 判断 a 是否大于或等于 b。 |
| `a <= b` | 判断 a 是否小于或等于 b。 |
| `a and b` | 判断两个 bool 数据或表达式 a、b 是否均为真值。 |
| `a or b` | 判断两个 bool 数据或表达式 a、b 的任意之一是否为真值。 |

上述六个比较运算符的结果类型都是 `bool`。

U 语言的三元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `a ? b : c` | 条件表达式。a 是条件, b 和 c 是两个分支。 |
| `a in b, c` | 区间判断。b 和 c 分别是下界和上界, 边界可以写为 `none`。 |

例如, `age in 0, 18` 写出了两个边界, `age in none, -1` 只写出上界。

### V. 分隔符

**分隔符, Spiltor**, 简写 Spt, 在 U 语言中用于分隔语句, 划定作用域。U 语言具有下列分隔符号:

`;` `(` `)` `[` `]` `{` `}` `,`

其中, 分号 `;` 表示一个语句的终结。小括号 `()` 用于提升表达式的优先级, 方括号 `[]` 是下标运算符, 花括号 `{}` 是作用域的界限。逗号 `,` 分隔不同表达式。

### VI. 字面量

**字面量, Literal**, 简写 Lit, 在源代码中直接表示整数、浮点数、字符或字符串等值。

#### 1. 整数

整数有下列写法:

| 写法 | 示例 | 十进制数值 | 规则 |
| :--- | :--- | :--- | :--- |
| 十进制 | 42 | 42 | 非 0 数字打头, 没有小数点的纯阿拉伯数字序列。(单独 0 除外) |
| 八进制 | 033 | 27 | 前导 0 打头, 后跟 0\~7 阿拉伯数字。 |
| 二进制 | 0b110 | 6 | 前导 0b 打头, 后跟 0 或 1 数字。 |
| 十六进制 | 0x0f | 15 | 前导 0x 打头, 后跟 0\~9 阿拉伯数字以及 a\~f 字母。 |

此外, `-5` 表示一元运算符 `-` 和整数字面量 `5` 结合的表达式。上述二进制和十六进制数据的前导和数据段的字母不区分大小写。也就是说, `0x7c00` 和 `0X26FA` 都是合法的。

#### 2. 浮点数

浮点数字面量采用十进制小数写法, 例如 `3.14` 和 `0.5`。小数点写作半角点号 `.`, 两侧都必须至少有一位十进制数字, 因此 `.5` 和 `5.` 都不是合法的浮点数字面量。

浮点数字面量中的前导零不改变进制, 例如 `033.0` 表示十进制的 33。`-3.14` 中的 `-` 是一元运算符。

浮点数字面量不带类型后缀。

#### 3. 字符

字符字面量使用半角单引号包围。引号内可以直接写一个字符, 也可以写一个转义序列。转义后的内容必须恰好表示一个 Unicode 标量值。空字符字面量、含有多个字符的字面量和含有源码换行的字面量均不合法。

字符和字符串字面量共用下列转义序列, 每个序列都以半角反引号（U+0060）开头:

| 转义序列 | 含义 |
| :--- | :--- |
| ``` `` ``` | 半角反引号。 |
| `` `' `` | 半角单引号。 |
| `` `" `` | 半角双引号。 |
| `` `n `` | 换行符 U+000A。 |
| `` `r `` | 回车符 U+000D。 |
| `` `t `` | 水平制表符 U+0009。 |
| `` `0 `` | 空字符 U+0000。 |

字面量中的反引号写成两个连续的反引号。反斜杠可直接写入, 与外层引号相同的引号必须转义。遇到表中未定义的转义序列时, 编译器应当报错。

可以编码为单个 UTF-8 字节的字符可用于 `char` 或 `rune`, 例如 `'A'` 和 `` '`n' ``。需要多个 UTF-8 字节的字符只能用于 `rune`, 例如 `'中'`。

```text
letter: char = 'A';
han: rune = '中';
```

#### 4. 字符串

字符串字面量使用半角双引号包围, 引号内可以有零个或多个字符。`""` 表示空字符串。字符串沿用字符字面量的转义规则, 可以用 `` `" `` 表示内容里的双引号, 用 `` `n `` 表示换行。字符串字面量不能直接跨源码行。

同一字面量写法可用于 `string` 和 `string32` 声明。

```text
message: string = "Hello`nU Language";
message32: string32 = "你好`nU 语言";
empty: string = "";
```

##### 插值字符串

在字符串的起始双引号前紧接小写字母 `f`, 即可写成插值字符串。字符串正文中的 `{Expression}` 表示一个插值位置。花括号内必须有一个完整的 U 语言表达式, 空的 `{}` 不合法。

插值位置以外的正文沿用普通字符串的反引号转义规则。正文中的 `{{` 和 `}}` 分别表示单个左花括号和右花括号。除了用来包围插值表达式的花括号, 正文中单独出现的花括号会导致语法错误。普通字符串中的花括号按原样保留。

例如, `f"hello, {name}!"` 用标识符作插值表达式。`f"{{{1 + 2}}}"` 在插值位置两侧各写了一对表示字面花括号的符号。

### VII. 注释

**注释, Comment**, 简写 com, 是源代码中的说明文字。U 语言有两种注释:

- 单行注释: `// Comments...`
- 多行注释: `/* Comments... */`

就如同 C++ 语言当中一样。其中, 多行注释是允许嵌套的, 即您可以编写 `/* Comments /* Comments */ Comments */`, 注释不会在最后一个 Comments 前截断。

## 语法

### I. 表达式

**表达式, Expression**, 简写 Expr, 可以出现在初始化式、实参、条件和 `return` 的操作数等位置。一个表达式可以包含其他表达式。

#### 1. 原子表达式

**原子表达式, Atom Expression**, 简写 Expr.Atom, 可以由一个字面量或标识符构成。

- **字面量表达式, Literal Expression**。字面量可以直接构成表达式, 例如整数 `42` 和字符串 `"string"`。
- **标识符表达式, Identifier Expression**, 简写 Expr.Id。标识符可以直接构成表达式。例如, 在 `age + 1` 中, `age` 是加法的左操作数。

#### 2. 条件表达式

**条件表达式, Conditional Expression**, 简写 Expr.Condit, 采用 `a ? b : c` 的形式。`a` 是 `bool` 类型的条件, `b` 和 `c` 是两个分支, 各自可以是表达式或 `return` 语句。

```ul
x >= 0 ? x : -x
```

#### 3. 运算表达式

**运算表达式, Operator Expression**, 简写 Expr.Calc, 由运算符和它的操作数组成。操作数本身可以是表达式。括号可以显式指定表达式的分组。

##### 比较运算

比较表达式使用 `>`、`<`、`>=`、`<=`、`==` 或 `!=` 连接两个操作数, 例如 `a == 3`。

`>`、`<`、`>=`、`<=` 的优先级相同, 均高于优先级相同的 `==` 和 `!=`。连续的相等比较从左向右分组。

| 表达式 | 分组 |
| :--- | :--- |
| `a == b == flag` | `(a == b) == flag` |
| `a == b > c` | `a == (b > c)` |

##### 逻辑运算

`and` 和 `or` 是二元逻辑运算符, `not` 是一元逻辑运算符。逻辑运算的操作数和结果都是 `bool`。`not ready` 和 `not (a and b)` 都是合法的写法, 其中 `ready`、`a` 和 `b` 是布尔值。

比较运算的优先级高于 `not`, `not` 的优先级高于 `and`, `and` 的优先级高于 `or`。例如:

| 表达式 | 分组 |
| :--- | :--- |
| `not a == b and a == c` | `(not (a == b)) and (a == c)` |
| `a == 2 and b == 3 or a + b == 5` | `((a == 2) and (b == 3)) or ((a + b) == 5)` |
| `not a + b == c` | `not ((a + b) == c)` |

##### 四则运算

`*` 和 `/` 的优先级相同, 高于优先级相同的 `+` 和 `-`。这些算术运算的优先级高于比较运算。相同优先级的四则运算从左向右分组。例如, `a + b * c` 解析为 `a + (b * c)`, `a - b - c` 解析为 `(a - b) - c`。

##### 赋值运算

赋值表达式采用 `左操作数 = 右操作数` 的形式。左操作数必须表示可写的位置。例如, `test = a;` 是一条表达式语句。需要值的位置不能使用赋值表达式, 例如 `f(a = b)` 和 `a = b = c` 都不合法。

> **编译规则**　如果左操作数是常量表达式, 编译器应报告 `Constant expression is unexpected here.`

结构体实例还支持以花括号中的值列表按成员声明顺序赋值。见「结构体 → 按位置赋值」。

#### 4. 调用表达式

**调用表达式, Call Expression**, 简写 Expr.Call, 由被调用部分和紧随其后的实参列表组成。以标识符调用函数的基本形式是 `Id(...)`。实参列表用圆括号包围, 可以为空。多个实参之间用逗号分隔。例如, `get_current_date()` 不传入实参, `f(x, y)` 传入两个实参。

在 `a: int32 = get_current_date();` 中, 调用表达式是变量 `a` 的初始化式。

匿名函数表达式的写法见「声明和定义 → 函数」。

### II. 语句

**语句, Statement**, 简写 Stmt, 可以出现在函数体等块内。分号是否属于一条语句, 由该语句的形式决定。

#### 1. 块语句

**块语句, Block Statement**, 简写 Stmt.Block, 用 `{` 和 `}` 包围一组语句, 并引入一个作用域。块可以嵌套。在函数体和控制流主体中, 块内可以依次写多条语句。

#### 2. 表达式语句

**表达式语句, Expression Statement**, 简写 Stmt.Expr, 由一个表达式和结尾的分号组成。

例如, `putln("hello, world!")` 是调用表达式, `putln("hello, world!");` 是表达式语句。

匿名函数表达式也可以加上分号独立成句。见「声明和定义 → 函数」。

#### 3. 声明语句

**声明语句, Declaration Statement**, 简写 Stmt.Decl, 是写在块内的一条声明。例如, `age: int32;` 和 `type_times: int32 = 0;` 都是声明语句。变量和常量声明的各部分见「声明和定义」。

#### 4. if-else 语句

`if` 后面是 `bool` 类型的条件, 紧接一个块或一条语句。可以追加 `else` 分支, 其主体同样可以是一个块或一条语句。把另一条 `if` 语句写作 `else` 的主体可构成 `else if`。

```ul
if ask_for_age(age) break;
```

[→ 查看附带示例](../examples/getstart.ul)

#### 5. for 语句

`for` 支持遍历形式和三段式。两种形式的循环体都可以是一个块或一条语句。

**遍历形式**写作 `for a in b`, 其中 `a` 是迭代变量名, `b` 是数组、切片或字符串表达式。

```ul
for item in items {
    use(item);
}
```

**三段式**写作 `for 初始化; 条件; 更新`, 后面接循环体。循环头的三个部分用分号分隔。

```ul
for i: int32 = 0; i < 3; ++i {
    use(i);
}
```

#### 6. while 语句

`while` 后面是 `bool` 类型的条件, 紧接一个块或一条语句。例如, `while ready { work(); }` 的循环体是一个块。

#### 7. switch-case 语句

`switch` 后面是被匹配的表达式, 接着用花括号包围各个 `case` 分支, 并以分号结束整个 `switch` 语句。每个 `case` 由一个匹配值和一个块组成。分支之间用逗号分隔, 最后一个分支后的逗号可以省略。

被匹配的表达式须支持 `==` 比较。各普通分支的匹配值不得相同。`case none` 是默认分支, 最多出现一次。

```ul
switch text {
    case "yes" { accept(); },
    case "no" { reject(); },
    case none { retry(); },
};
```

#### 8. 跳转语句

- `break;` 和 `continue;` 可以写在循环体中。
- `return 表达式;` 带一个返回值表达式。无返回值的函数可以写 `return;`。

#### 9. 错误处理语句

##### 报告错误

报告语句采用 `report 表达式;` 的形式, 其中表达式用于指定错误值。

```ul
fn test() {
    report "error";
}
```

##### 补救措施

`failed` 后面写要监测的调用, 再写一个块。这个块称为**补救措施**。

```ul
failed test() {
}
```

带错误值的形式在 `failed` 和调用之间写接收错误值的标识符, 在调用之后用冒号标注错误值的类型。

```ul
failed err test(): string {
    putln(err);
}
```

这里的 `: string` 标注的是 `err` 的类型。

`failed` 后也可以写包含调用的赋值表达式, 例如 `failed age = string_to_int(input) { ... }`。

### III. 声明和定义

声明给出名字和与它关联的类型或签名。函数定义还提供函数体。语句章说明声明如何作为块内的一条语句, 本章说明声明本身的写法。

#### 1. 变量和常量

变量声明采用 `名称: 类型;` 的形式。需要提供初值时, 写作 `名称: 类型 = 初始化式;`。在声明中, `=` 引出初始化式。

```ul
age: int32;
type_times: int32 = 0;
limit: int32! = 10;
```

第三条声明在类型后加 `!`, 将 `limit` 声明为只读。

类型名后可写**附加描述, Extern Description**。附加描述可以组合, 从右向左解释。

| 类型写法 | 含义 |
| :--- | :--- |
| `T!` | 只读的 `T`。 |
| `T[]` | 元素类型为 `T` 的切片。 |
| `T[n]` | 元素类型为 `T`、长度为 `n` 的数组。 |
| `T[]!` | 只读数组。写法中省略长度, 数组长度固定, 元素不可修改。 |
| `T[n]!` | 只读数组。数组长度由 `n` 给出, 元素不可修改。 |
| `T[]![]!` | 二维只读数组。两层数组的长度均固定, 元素均不可修改。 |

##### 指针、引用和只读视图

指针、可写引用和只读视图的类型标记写在目标类型之前。

| 类型写法 | 含义 | 声明示例 |
| :--- | :--- | :--- |
| `->T` | 指向 `T` 类型对象的指针。 | `ptr: ->int32 = &3;` |
| `&T` | 对 `T` 类型对象的可写引用。 | `ref: &int32 = refer;` |
| `@T` | 对 `T` 类型对象的只读视图。 | `view: @int32 = value;` |

这些类型标记可以嵌套。每个标记作用于其右侧的完整类型, 最左侧的标记构成最外层类型。

- `@->int32` 是对 `->int32` 指针的只读视图。视图的目标是指针本身。
- `->@int32` 是指向 `@int32` 只读视图的指针。
- `->&int32` 是指向 `&int32` 引用的指针。

#### 2. 函数

具名函数以 `fn` 开头, 后接函数名和用圆括号包围的形参列表。形参写作 `名称: 类型`, 多个形参用逗号分隔。没有形参时保留空括号。圆括号后可以写 `: 返回类型`。

函数定义以块作为函数体。只声明函数时, 在签名末尾写分号。例如:

```ul
fn answer(): int32;

fn answer(): int32 {
    return 42;
}
```

返回类型写为 `none` 或省略返回类型, 都表示函数无返回值。`fn f(): none { ... }` 和 `fn f() { ... }` 是等价的定义形式, `fn f(): none;` 和 `fn f();` 是等价的声明形式。

##### 匿名函数表达式

**匿名函数表达式, Anonymous Function Expression**, 采用 `fn(形参列表) { ... }` 的形式。`fn` 后紧接形参列表, 没有形参时写成 `fn()`, 然后写用花括号包围的函数体。

匿名函数表达式通常用作赋值运算的右操作数, 也可以写在声明的 `=` 后作为初始化式, 例如 `subtotal: int32 = fn() { return 42; };`。声明左侧采用 `名称: 类型` 的形式。只有在以 `fn` 开头的具名函数声明或定义中, 函数名后才写形参列表, 因此 `subtotal(): int32 = fn() { return 42; };` 不合法。

匿名函数表达式不能直接作为调用实参。匿名函数表达式后接分号时, 构成一条**匿名函数语句**, 形式为 `fn(形参列表) { ... };`。

匿名函数必须带函数体。`test: int32 = fn();` 缺少函数体, 因此不合法。

普通函数内可以用匿名函数表达式初始化局部声明, 匿名函数体内也允许这种声明, 因此匿名函数可以嵌套。例如:

```ul
fn calculate(): int32 {
    subtotal: int32 = fn() {
        base_value: int32 = fn() {
            return 40;
        };
        return base_value() + 2;
    };
    return subtotal();
}
```

#### 3. 结构体

结构体定义以 `struct` 开头, 后接结构体名和用花括号包围的成员声明列表, 最后以分号结束。结构体体内只允许成员声明。数据成员可以写成 `名称: 类型;` 或 `名称: 类型 = 初值;`。

```ul
struct Position {
    row: int32;
    column: int32 = 4;
};
```

##### 方法

推荐在结构体体外定义方法。方法定义在形参列表后写 `in 结构体名`, 然后写返回类型和函数体。例如:

```ul
fn origin_index() in Position: int32 {
    return 0;
}
```

结构体内也允许声明一个以匿名函数表达式初始化的成员。成员声明采用 `名称: 类型 = fn(形参列表) { ... };` 的形式, 形参列表紧跟在右侧的 `fn` 后。

```ul
struct Counter {
    count: int32 = 0;
    initial_count: int32 = fn() {
        return 0;
    };
};
```

> **编译规则:**　对这种成员声明, 编译器应报告一条 Tip。以 `Counter` 中的 `initial_count` 为例, 提示为 `using fn initial_count() in Counter is recommended.`

##### 按位置赋值

结构体实例可以用 `实例 = {值, 值, ...};` 按位置赋值。花括号内的各项按成员声明顺序排列, 用逗号分隔。`none` 用作跳过对应成员的占位符。

```ul
position: Position;
position = {42, 42};
position = {none, 17};
```
