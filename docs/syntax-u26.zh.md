# U 编程语言语法规范文档 (U26 标准)

ZirconiumTian, 2026 年 11 月 21 日

## 词法

### I. 标识符

**标识符, Identifier**, 简写 Id, 是 U 编程语言 (下列简称 U 语言) 在源代码中用于描述变量、函数、成员、方法、结构体等使用的词法元素。适用的字符范围是 `[A~Za~z0~9_]`, 也就是所有半角大小写字母、半角阿拉伯数字和下划线, 并且以 **非阿拉伯数字** 打头。下列:

- `function_name`
- `Tokenizer`
- `decodeUTF32`

都是合法的例子。

特别地, 作为 Identifier, U26 不会阻止您使用一些全角或半角的 Unicode 字符。除了下列 Unicode 空格和标点不被允许:

| 字符 | Unicode 码点 | 字符 | Unicode 码点 |
| :--- | :--- | :--- | :--- |
| `　` | U+3000 | `、` | U+3001 |
| `‘` | U+2018 | `’` | U+2019 |
| `“` | U+201C | `”` | U+201D |
| `：` | U+FF1A | `；` | U+FF1B |
| `，` | U+FF0C | `。` | U+3002 |

那么, 以一些中文 Unicode 字符举例:

| 标识符 | 是否合法 | 标识符 | 是否合法 |
| :--- | :--- | :--- | :--- |
| `甲乙` | 是 | `甲，乙` | 不是 |
| `“”` | 否 | `你好U语言` | 是 |
| `→here` | 是 | `Software：Installer` | 不是 |

当然, 介于应用不同语言地区设置的不同操作系统平台, 源代码文件的编码可能会有所不同, 因此并不推荐大量在标识符命名中使用 Unicode 字符。

> **编译规则**: 使用合法 ASCII 和 Unicode 字符命名的非关键字和非类型名的标识符, 编译器 **不应** 报错或给出警告。<br>
> 报告错误为: `Unexpected character in identifiers.`

U 语言的标识符命名不能和关键字或类型名冲突。

### II. 关键字

**关键字, Keyword**, 简写 Kwd, 在词法层面上是一组特殊的标识符。它们分别是:

| 关键字 | 含义 |
| :--- | :--- |
| `and` | 逻辑与。 |
| `break` | 在一个 while 或 for 循环中终止并离开循环块。 |
| `case` | 在 switch 语句中使用。 |
| `continue` | 在一个 while 或 for 循环中终止并回到循环起始位置。 |
| `else` | else 条件分支语句。 |
| `failed` | 适用于错误处理块, 声明一个补救方案。 |
| `false` | 布尔字面量, 表示假值。 |
| `fn` | 声明一个函数。 |
| `for` | for 循环语句。 |
| `if` | if 条件分支语句。|
| `in` | in 语句, 可以在 for 语句中使用, 或者用于判断一个整数或者浮点数是否在指定的值大小范围内, 也可以用于结构体成员的外部实现。 |
| `or` | 逻辑或。 |
| `none` | 通用关键字, 表示空数据或者无返回值函数的返回类型。 |
| `not` | 逻辑非。 |
| `report` | 报告一个错误, 被 failed 语句监听和捕获。 |
| `return` | 返回语句, 用户函数和方法中。 |
| `struct` | 结构体声明。 |
| `switch` | 声明一个 switch 语句。 |
| `true` | 布尔字面量, 表示真值。 |
| `using` | 模块调用。仅仅可以在全局作用域或者全局作用域下的第一层 if else 中使用。 |
| `while` | while 循环语句。 |

此外, 有一些 **内建方法**, 它们遵循一些别的规则。详见章节 **语法和语义 > III**。上述关键字不能被用作标识符的命名。

> **编译规则**: 使用关键字命名的标识符应该报错并拒绝进一步编译。<br>
> 报告错误为: `Should not be used here as an identifier`。

### III. 类型名

**类型名, TypeName**, 简写 Type, 是 U 语言中描述数据类型的特殊标识符。它们分别是:

| 类型名 | 含义 |
| :--- | :--- |
| `int8` | 数据宽 7 的整数。 |
| `int16` | 数据宽 15 的整数。 |
| `int32` | 数据宽 31 的整数。 |
| `int64` | 数据宽 63 的整数。 |
| `uint8` | 位宽为 8 的无符号整数。 |
| `uint16` | 位宽为 16 的无符号整数。 |
| `uint32` | 位宽为 32 的无符号整数。 |
| `uint64` | 位宽为 64 的无符号整数。 |
| `char` | 位宽为 8 的字符数据, string 类型数据的元素类型。<br>在 U 语言中 `ch: char = 65` ch 会优先以 `'A'` 被调用而非 65。 |
| `rune` | 位宽为 32 的字符数据, string32 类型数据的元素类型。调用行为如上 rune 栏所示。 |
| `string` | UTF-8 字符串。 |
| `string32` | UTF-32 字符串。 |
| `float32` | 数据位 31 的浮点数。 |
| `float64` | 数据位 63 的浮点数。 |
| `bool` | 布尔数据。 |

上述类型名不能被用作标识符的命名。

> **编译规则**: 使用类型名命名的标识符应该报错并拒绝进一步编译。<br>
> 报告错误为: `Should not be used here as an identifier`。

### IV. 运算符

**运算符, Operator**, 简写 Op, 是 U 语言中用于在数据间表达运算或传递关系的符号。运算符分为 **一元运算符, Unary Operator**、**二元运算符, Binary Operator** 和 **三元运算符, Tripleray Operator**。

一些运算符写作关键字。

| 元 | 一般格式 | 常见运算 |
| :--- | :--- | :--- |
| 1 | `[Op][Id]` | 指针、引用、视图、布尔取反、自增自减和下标等。 |
| 2 | `[Id][Op][Id]` | 数学四则运算、布尔比较等。 |
| 3 | `[Id][Op][Id][Op][Id]` | `?:` 条件运算、`in` 区间判断。 |

U 语言的一元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `not a` | 对数据或表达式 a 布尔取反。 |
| `&a` | 数据 a 的可写引用。 |
| `@a` | 数据 a 的只读视图。 |
| `->a` | 数据 a 的指针指向关系/地址。 |
| `~a` | 对一个整数或者浮点数及对应表达式 a 的数据按位颠倒。 |
| `++a` | 对整数 a 自增 1。 |
| `--a` | 对整数 a 自减 1。 |
| `-a` | 取相反数, 前提是 a 的数据类型为 float, int 的任意之一。 |

U 语言的二元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `a + b` | 对整数或者浮点数 a、b 求和。 |
| `a - b` | 对整数或者浮点数 a、b 求差。 |
| `a * b` | 对整数或者浮点数 a、b 求乘积。 |
| `a / b` | 对整数或者浮点数 a、b 求商。表达式或数据 b 不能为 0。 |
| `a[b]` | 下标运算, 访问切片或数组 a 的第 b 个元素。b 只能为 int 或 uint 类型。 |
| `a.b` | 访问结构体 a 的成员/方法 b，或者访问对特定数据 a 使用内建方法 b。 |
| `a = b` | 将 b 的数据传递到 a。是复制、指向还是视图取决于具体数据类型。 |
| `a > b` | 判断 a 是否大于 b。 |
| `a < b` | 判断 a 是否小于 b。 |
| `a == b` | 判断 a 是否等于 b。 |
| `a != b` | 判断 a 是否不等于 b。 |
| `a >= b` | 判断 a 是否大于或等于 b。 |
| `a <= b` | 判断 a 是否小于或等于 b。 |
| `a and b` | 判断两个 bool 数据或表达式 a、b 是否均为真值。 |
| `a or b` | 判断两个 bool 数据或表达式 a、b 的任意之一是否为真值。 |

上述六个比较运算符的结果类型都是 `bool`。

U 语言的三元运算符:

| 运算符 | 含义 |
| :--- | :--- |
| `a ? b : c` | a 是布尔数据或表达式。a 为 `true` 时只求值或执行 b, 为 `false` 时只求值或执行 c。 |
| `a in b, c` | 判断整数或浮点数 a 是否落在以 b 为下界、c 为上界的区间内, 结果类型为 `bool`。两个端点均包含在区间内。边界写成 `none` 时, 省去该侧的比较。 |

例如, 下列写法:

- `age in 0, 18` 等价于 `(age >= 0) and age <= 18)`
- `age in none, -1` 等价于 `age <= -1`

### V. 分隔符

**分隔符, Spiltor**, 简写 Spt, 在 U 语言中用于分隔语句, 划定作用域。U 语言具有下列分隔符号:

`;` `(` `)` `[` `]` `{` `}` `,`

其中, 分号 `;` 表示一个语句的终结。小括号 `()` 用于提升表达式的优先级, 方括号 `[]` 是下标运算符, 花括号 `{}` 是作用域的界限。逗号 `,` 分隔不同表达式。

### VI. 字面量

**字面量, Literal**, 简写 Lit, 在 U 语言中用于表示编译期可以确定的原始数据。它们分为下面几种数据:

#### i. 整数

整数有下列写法:

| 写法 | 示例 | 十进制数值 | 规则 |
| :--- | :--- | :--- | :--- |
| 十进制 | 42 | 42 | 非 0 数字打头, 没有小数点的纯阿拉伯数字序列。(单独 0 除外) |
| 八进制 | 033 | 27 | 前导 0 打头, 后跟 0~7 阿拉伯数字。 |
| 二进制 | 0b110 | 6 | 前导 0b 打头, 后跟 0 或 1 数字。 |
| 十六进制 | 0x0f | 15 | 前导 0x 打头, 后跟 0~9 阿拉伯数字以及 a~f 字母。 |

此外, `-5` 表示一元运算符 `-` 和整数字面量 `5` 结合的表达式。上述二进制和十六进制数据的前导和数据段的字母不区分大小写。也就是说, `0x7c00` 和 `0X26FA` 都是合法的。

#### ii. 浮点数

浮点数字面量采用十进制小数写法, 例如 `3.14` 和 `0.5`。小数点写作半角点号 `.`, 两侧都必须至少有一位十进制数字, 因此 `.5` 和 `5.` 都不是合法的浮点数字面量。

浮点数字面量中的前导零不改变进制, 例如 `033.0` 表示十进制的 33。`-3.14` 中的 `-` 是一元运算符。

浮点数字面量不带类型后缀。上下文要求 `float32` 或 `float64` 时, 字面量采用相应的类型。上下文未指定浮点类型时, 默认采用 `float64`。

#### iii. 字符

字符字面量使用半角单引号包围。引号内可以直接写一个字符, 也可以写一个转义序列。转义后的内容必须恰好表示一个 Unicode 标量值。空字符字面量、含有多个字符的字面量和含有源码换行的字面量均不合法。

字符和字符串字面量共用下列转义序列, 每个序列都以半角反引号（U+0060）开头:

| 转义序列 | 含义 |
| :--- | :--- |
| ``` `` ``` | 半角反引号。 |
| `` `' `` | 半角单引号。 |
| `` `" `` | 半角双引号。 |
| `` `n `` | 换行符 U+000A。 |
| `` `r `` | 回车符 U+000D。 |
| `` `t `` | 水平制表符 U+0009。 |
| `` `0 `` | 空字符 U+0000。 |

字面量中的反引号写成两个连续的反引号。反斜杠可直接写入, 与外层引号相同的引号必须转义。遇到表中未定义的转义序列时, 编译器应当报错。

可以编码为单个 UTF-8 字节的字符可用于 `char` 或 `rune`, 例如 `'A'` 和 `` '`n' ``。需要多个 UTF-8 字节的字符只能用于 `rune`, 例如 `'中'`。上下文未指定字符类型时, 前一种默认采用 `char`, 后一种采用 `rune`。例如:

```text
letter: char = 'A';
han: rune = '中';
```

#### iv. 字符串

字符串字面量使用半角双引号包围, 引号内可以有零个或多个字符。`""` 表示空字符串。字符串沿用字符字面量的转义规则, 可以用 `` `" `` 表示内容里的双引号, 用 `` `n `` 表示换行。字符串字面量不能直接跨源码行。

同一写法可用于 `string` 和 `string32`。`string` 将内容编码为 UTF-8, 元素类型为 `char`。`string32` 将内容编码为 UTF-32, 元素类型为 `rune`。上下文未指定字符串类型时, 默认采用 `string`。例如:

```text
message: string = "Hello`nU Language";
message32: string32 = "你好`nU 语言";
empty: string = "";
```

##### 插值字符串

在字符串的起始双引号前紧接小写字母 `f`, 即可写成插值字符串。字符串正文中的 `{Expression}` 表示一个插值位置。求值时, 各插值位置中的表达式从左到右求值一次, 并将结果的文本表示插入对应位置。插值位置必须包含一个完整的 U 语言表达式, 空的 `{}` 不合法。

插值位置以外的正文沿用普通字符串的反引号转义规则。正文中的 `{{` 和 `}}` 分别表示单个左花括号和右花括号。除了用来包围插值表达式的花括号, 正文中单独出现的花括号会导致语法错误。普通字符串中的花括号按原样保留。

插值字符串的结果类型沿用普通字符串的规则。例如, 当 `name` 的值为 `"U"` 时, `f"hello, {name}!"` 得到 `"hello, U!"`。`f"{{{1 + 2}}}"` 得到 `"{3}"`。

### VII. 注释

**注释, Comment**, 简写 com, 是 U 语言中对特定代码进行说明的而不影响任何代码逻辑和编译行为的文本部分。U 语言有两种注释:

- 单行注释: `// Comments...`
- 多行注释: `/* Comments... */`

就如同 C++ 语言当中一样。其中, 多行注释是允许嵌套的, 即您可以编写 `/* Comments /* Comments */ Comments */`, 注释不会在最后一个 Comments 前截断。
